# Welcome to My Laboratory Exercise Repository! 🚀

This repository is dedicated to storing all of my laboratory exercises, quizzes, and exams from **Ma'am's class**. Each folder represents a different session, containing the corresponding **Java programs**, activities, and assessments assigned throughout the course.

## Repository Structure 📁

- **Laboratory 1:**  
   Contains the Java programs and exercises from the **first lab session**.

- **Laboratory 2:**  
   Contains the Java programs and exercises from the **second lab session**.

- **Laboratory 3 - Group Activity:**  
   Includes group projects, Java programs, and activities from the **third lab session**.

- **Quizzes:**  
   Contains all quizzes and assessments conducted throughout the course.

- **Exams:**  
   Contains the **midterm** and **final exam programs**, showcasing comprehensive problem-solving and Java skills.

## Purpose 🎯

This repository serves as:  
1. **A Personal Archive**: To track my progress and improvements throughout the course.  
2. **A Learning Resource**: To revisit and review Java programs, quizzes, and exams for better understanding.  
3. **A Portfolio**: Showcasing the programming tasks, assessments, and group collaborations completed during the course.
